# The Admin Portal's Core Purpose

At the highest level, the portal should allow an authorized MGTV team member to answer:

> **"Can I run the entire digital MGTV platform from here?"**

If the answer is yes, the admin portal is doing its job.

A staff member should be able to go from:

**Content → Media → Publishing → Homepage → Subscribers → Sponsors → Advertising → Events → Awards → Analytics → Settings**

without needing a developer to make routine platform changes.

That is the distinction I would preserve in the Figma design: **the customer application is where the audience experiences MGTV; the Admin Portal is where MGTV operates MGTV.**
